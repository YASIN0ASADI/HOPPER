## Hopper چیه؟

Hopper جواب سؤال‌هایی رو می‌ده که موقع نگه‌داشتن سرور، مخصوصاً توی شرایط اینترنت ایران، مدام ازشون می‌پرسی:

- سرورم از **داخل ایران** در دسترسه یا IP/پورتش فیلتره؟
- چه پورت‌هایی بازه و پشت این IP چیه؟
- مسیر BGP تا این prefix چه شکلیه؟
- SSL یا دامنه‌م کی منقضی می‌شه؟
- تا من خواب بودم سرورم قطع شد یا نه؟

بیشتر ابزارها فقط از **منابع عمومی** داده می‌گیرن (Shodan InternetDB، لاگ‌های Certificate Transparency، RIPEstat، check-host.net، RDAP و ...). فقط چک پورت و تاخیر TCP و مانیتور به سرور هدف وصل می‌شن، اونم با یه اتصال TCP ساده و نه بیشتر.

## امکانات

### 🖧 ابزارهای سرور و VPN
| ابزار | کار |
|---|---|
| 🌐 **اطلاعات IP** | موقعیت جغرافیایی، ASN، reverse DNS و پورت‌ها/سرویس‌ها/CVE های شناخته‌شده از Shodan InternetDB. برای آی‌پی‌های خصوصی هم توضیح می‌ده. |
| 🔌 **چک پورت** | اتصال TCP به پورت‌های رایج یا دلخواه و تشخیص سرویس. برای هر کاربر محدودیت نرخ داره. |
| 🇮🇷 **چک از ایران** | دسترسی `host:port` از چند نود داخل ایران و چند نود شاهد خارج، همراه با نتیجه‌گیری (فیلتر یا خاموش). |
| 🏓 **پینگ جهانی** | پینگ از نودهای ایران یا همه‌ی نودهای check-host، مرتب‌شده از سریع به کند. |
| ⚡ **تاخیر TCP** | اندازه‌گیری زمان اتصال تا ۵ سرور برای مقایسه. |
| 📡 **مانیتور** | هشدار قطع و وصل با نمودار ۲۴ ساعته. «پایش فیلتر» خودکار از ایران هم اختیاریه. |
| 🧾 **تحلیل `ss -tulpn`** | خروجی دستور رو paste کن؛ پورت‌های در حال استفاده، برنامه‌ی پشتشون، پورت‌های فقط داخلی، دیتابیس‌های در معرض خطر و پورت‌های آزاد پیشنهادی رو می‌گیری. |
| 🎭 **چک Reality** | بررسی دامنه‌ی `dest`: TLS 1.3، HTTP/2، گواهی و تاخیر. |
| 🔗 **تحلیل لینک کانفیگ** | لینک‌های `vless://` و `vmess://` و `trojan://` و `ss://` رو تحلیل می‌کنه و تنظیمات ضعیف رو نشون می‌ده. کلیدها ماسک می‌شن و چیزی ذخیره نمی‌شه. |
| 🕸 **نقشه‌ی ASN / BGP** | نقشه‌ی مسیر AS شبیه bgpmap، از داده‌ی RIPEstat. |

### 🌍 ابزارهای وب و دامنه
| ابزار | کار |
|---|---|
| 🔎 **DNS** | رکوردهای A / AAAA / MX / NS / TXT با DNS-over-HTTPS. |
| 🧭 **DNS از ایران** | مقایسه‌ی جواب DNS نودهای ایران با نودهای شاهد خارج (تشخیص DNS poisoning و صفحه‌ی مسدودی). |
| 🧩 **ساب‌دامین‌ها** | ادغام ۵ منبع غیرفعال (crt.sh، CertSpotter، AnubisDB، OTX، HackerTarget) و گزارش اینکه کدوم‌ها جواب دادن. |
| 📇 **Whois** | تاریخ ثبت و انقضا و name serverها با RDAP، و در صورت نیاز WHOIS مستقیم (پورت ۴۳). پسوند `.ir` هم پشتیبانی می‌شه. |
| 🔐 **SSL Info** | اعتبار، issuer، نوع کلید، SANها و پروتکل. پورت دلخواه هم ممکنه (`example.com:8443`). |
| 🛡 **هدرهای امنیتی** | HSTS و CSP و بقیه با نمره‌ی ساده. |
| 🧪 **بازرس HTTP** | مسیر ریدایرکت‌ها، وضعیت، هدرها و زمان‌ها، با محافظ SSRF در هر مرحله. |
| ✉️ **چک ایمیل** | SPF و DKIM و DMARC. |
| ⏰ **هشدار انقضا** | تا ۱۰ دامنه یا گواهی ثبت کن؛ ۳۰ و ۱۵ و ۷ و ۳ و ۱ و ۰ روز مونده بهت خبر می‌ده. |

### 👥 دستورهای گروه
ربات رو به گروه اضافه کن و با این دستورها ازش استفاده کن (آرگومان بنویس یا روی یه پیام ریپلای کن):

| دستور | کار |
|---|---|
| `/bgp AS13335` · `/bgp 1.1.1.1` · `/bgp example.com` | نقشه‌ی ASN / مسیر AS |
| `/ping example.com` | پینگ جهانی (همه‌ی نودها) |
| `/pingir example.com` | پینگ فقط از ایران |
| `/ip 1.1.1.1` | اطلاعات IP |

### ✨ بقیه‌ی امکانات
- **دو زبان:** موقع `/start` انتخاب می‌شه و برای هر کاربر ذخیره می‌شه. همه‌ی متن‌ها و خطاها و هشدارها با همون زبان میان.
- **ایموجی پرمیوم** توی متن پیام‌ها و آیکن دکمه‌ها، با برگشت خودکار به ایموجی معمولی اگه تلگرام قبول نکنه.
- **دکمه‌های رنگی** (`primary` / `success` / `danger`) روی نسخه‌های جدید تلگرام.
- ساعت تهران توی هشدارها، نمایش درست متن راست‌به‌چپ، و cooldown و سهمیه‌ی هر کاربر.

## نصب سریع

**پیش‌نیاز:** پایتون ۳.۱۰ یا بالاتر و توکن ربات از [@BotFather](https://t.me/BotFather).

> تلگرام توی ایران فیلتره؛ ربات رو روی سروری **خارج از ایران** اجرا کن.

```bash
git clone https://github.com/YASIN0ASADI/HOPPER.git
cd HOPPER

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN="123456:ABC-your-token"
python bot.py
```

توی تلگرام به ربات `/start` بده، زبان رو انتخاب کن و تمام.

## تنظیمات

همه‌ی تنظیمات با متغیر محیطی انجام می‌شه.

| متغیر | اجباری | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن BotFather. **هیچ‌وقت کامیتش نکن.** |
| `ADMIN_IDS` | – | آیدی عددی ادمین‌ها با کاما جدا شده، برای دستورهای ادمین. آیدی خودت رو با `/id` بگیر. |
| `DB_PATH` | – | فایل SQLite مانیتورها، هشدارهای انقضا و زبان کاربرها. پیش‌فرض: `monitor.db` کنار `bot.py`. |
| `EMOJI_PACKS` | – | اسم پک‌های ایموجی سفارشی (با کاما) که موقع استارت import می‌شن. |
| `EMOJI_MAP` | – | مسیر فایل نقشه‌ی ایموجی. پیش‌فرض: `emoji_map.json` کنار `bot.py`. |
| `PREMIUM_EMOJI` | – | مقدار `0` ایموجی پرمیوم رو کامل خاموش می‌کنه. |

نمونه‌ی آماده توی [`.env.example`](.env.example) هست.

## اجرا با systemd

فایل سرویس، ربات رو با یه کاربر بدون دسترسی و داخل یه sandbox محدود اجرا می‌کنه. پروژه باید توی `/bot` باشه.

```bash
# ۱) گرفتن کد
git clone https://github.com/YASIN0ASADI/HOPPER.git /bot
cd /bot

# ۲) محیط پایتون
apt update && apt install -y python3-venv python3-pip
python3 -m venv venv
./venv/bin/pip install -r requirements.txt

# ۳) کاربر جدا
useradd -r -s /usr/sbin/nologin reconbot
chown -R reconbot:reconbot /bot

# ۴) توکن (فقط root بتونه بخونه)
install -m 600 /dev/null /etc/recon-bot.env
nano /etc/recon-bot.env          # بنویس:  BOT_TOKEN=توکن   (و اختیاری ADMIN_IDS=123456789)

# ۵) سرویس
cp recon-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now recon-bot
```

دستورهای روزمره:

```bash
journalctl -u recon-bot -f                                    # لاگ زنده
systemctl restart recon-bot                                   # بعد از عوض کردن فایل‌ها
git pull && chown -R reconbot:reconbot /bot && systemctl restart recon-bot   # آپدیت
```

## ایموجی پرمیوم

برای نمایش ایموجی سفارشی توی پیام‌های ربات، **اکانت صاحب ربات باید Premium داشته باشه** (یا ربات یه یوزرنیم اضافه از Fragment داشته باشه). بدون اون هم ربات کار می‌کنه؛ تلگرام ایموجی رو رد می‌کنه و Hopper خودکار نسخه‌ی معمولی رو دوباره می‌فرسته.

دستورهای مخصوص ادمین (اول `ADMIN_IDS` رو تنظیم کن):

| دستور | کار |
|---|---|
| `/id` | آیدی عددی تلگرامت رو نشون می‌ده (برای همه فعاله). |
| `/pack <لینک یا اسم>` | همه‌ی ایموجی‌های یه پک رو import می‌کنه. |
| `/sync` | پک‌های `EMOJI_PACKS` رو دوباره می‌خونه. |
| `/map 🌐 <ایموجی پرمیوم>` | یه ایموجی معمولی رو به یه ایموجی پرمیوم مشخص وصل می‌کنه. |
| `/emojis` | نشون می‌ده کدوم ایموجی‌های رابط هنوز معمولی هستن. |
| *(ارسال یه ایموجی پرمیوم)* | ربات id ایموجی رو برمی‌گردونه. |

نقشه‌ها توی `emoji_map.json` ذخیره می‌شن (توسط git نادیده گرفته می‌شه).

## منابع داده

Hopper از سرویس‌های عمومی رایگان استفاده می‌کنه؛ لطفاً شرایط استفاده و محدودیت نرخشون رو رعایت کن:
[Shodan InternetDB](https://internetdb.shodan.io/) · [ipwho.is](https://ipwho.is/) · [Cloudflare DNS-over-HTTPS](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/) · [crt.sh](https://crt.sh/) · [CertSpotter](https://sslmate.com/certspotter/) · [AnubisDB](https://jldc.me/) · [AlienVault OTX](https://otx.alienvault.com/) · [HackerTarget](https://hackertarget.com/) · [RDAP](https://rdap.org/) · [check-host.net](https://check-host.net/) · [RIPEstat](https://stat.ripe.net/)

## امنیت و استفاده‌ی مسئولانه

- Hopper برای **بررسی سرورهایی که مال خودته یا ادمینشی** ساخته شده. چک پورت و تاخیر TCP و مانیتور مستقیم به هدف وصل می‌شن، پس روی سیستمی که اجازه‌ی تست نداری ازشون استفاده نکن.
- هدف‌هایی که به آدرس خصوصی یا loopback یا غیرعمومی resolve بشن رد می‌شن (محافظ SSRF).
- چک پورت برای هر کاربر ساعتی ۱۵ بار مجازه و بین هر دو درخواست یه cooldown کوتاه هست.
- لینک‌های کانفیگ فقط توی حافظه تحلیل می‌شن؛ کلیدها توی خروجی ماسک می‌شن و هیچ‌جا ذخیره یا ارسال نمی‌شن.
- ربات هیچ‌وقت دسترسی SSH یا پسورد نمی‌خواد. دستور `ss` رو خودت روی سرور بزن و خروجیش رو paste کن.
- **توکن ربات و فایل `monitor.db` رو هیچ‌وقت کامیت نکن.** اگه توکن لو رفت، تو BotFather با `/revoke` باطلش کن.

مسئولیت نحوه‌ی استفاده با خودته. برای سلب مسئولیت به [لایسنس](LICENSE) نگاه کن.
